# Encyclopédie Dofus — brisage

Encyclopédie perso des équipements de Dofus (Rétro, 2.x, 3.x Unity) pour repérer les objets
rarement craftés, intéressants à briser en runes.

En ligne : https://phyrise.github.io/dofus/

- `index.html` : l'interface (aucune dépendance, s'ouvre aussi en local par double-clic)
- `data/*.js` : données générées par version

## Sources des données

- Dofus 3 : API DofusDB (client 3.7.4), recoupée avec dofusdude (3.7.12)
- Dofus 2 : fichiers du client 2.73.3.14 extraits par dofusdude
- Dofus Rétro : fichiers « lang » du client officiel, drops depuis la base de l'émulateur StarLoco

Score de rareté et potentiel (marge craft + brisage) : estimations, à vérifier en jeu.
Les notes, favoris et relevés saisis dans l'interface restent dans le navigateur du visiteur.
